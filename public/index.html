Photos become listings

A vision model reads each photo and drafts a title, description, price, materials and the words shoppers and agents search for. It flags what a photo can't confirm, so the seller checks it. Publishing registers every product in the PayPal catalog.

The shop speaks to agents

Every shop page registers WebMCP tools (search_products, get_product, create_checkout, get_order_status), and the same tools are served over MCP, so a browser agent or any MCP client can shop without scraping the page.

The buyer approves in PayPal

An agent can prepare an order but never pay. create_checkout creates a PayPal order and hands back the approval link; the buyer signs in to PayPal and approves. The seller sees which agent placed each order and the tool calls behind it.
